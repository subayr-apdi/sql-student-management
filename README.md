# SQL Student Management

## Description

A beginner SQL project built using Microsoft SQL Server to manage student records in student.

## SQL Concepts Practiced

* Database and table creation (DDL)
* Inserting student records (DML)
* SELECT queries
* UPDATE and DELETE
* ALTER TABLE


## Table: student

Stores student IDs, names, email addresses, courses, enrollment dates, ages, and phone numbers.

## Tools

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
